# Telegram PC Remote Controller 🖥️📱

Многофункциональный Telegram бот с мобильным **Web App** интерфейсом для удаленного управления персональным компьютером с телефона.

## Возможности

1. **📱 Telegram Web App**: Красивый мобильный интерфейс, открывающийся прямо из Telegram.
2. **📸 Скриншот**: Мгновенный захват экрана вашего ПК и просмотр на экране телефона в высоком качестве.
3. **💻 Терминал PowerShell**: Выполнение любых команд PowerShell / CMD с выводом результата в реальном времени.
4. **⚙️ Диспетчер процессов**: Просмотр списка запущенных процессов, поиск и принудительное завершение процессов по PID.
5. **📊 Статус системы**: Информация о хосте, ОС и времени работы.

---

## Установка и запуск

1. Установите **Node.js** (если еще не установлен).
2. Перейдите в папку с ботом и установите зависимости:
   ```bash
   npm install
   ```
3. Запустите бота:
   ```bash
   npm start
   ```
4. Бот автоматически запустит локальный сервер и создаст публичный HTTPS-туннель через `localtunnel`, связав его с вашим Telegram ботом.
5. Откройте вашего бота в Telegram и отправьте команду `/start`. Нажмите на кнопку **"🚀 Открыть панель управления"**.
